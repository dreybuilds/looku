# Looku development

For interface additions, layout fixes, typography or spacing changes, read `DESIGN_SYSTEM.md` first. Reuse `dist/ui.js` and the tokens in `dist/ui.css`; extend their live gallery for new shared patterns. Apply the documented desktop and phone checks before release. Keep the landing page and merchant storefront identities separate from the app/admin system.

Preserve concurrent work on `main`. Use the repository's configured `dreybuilds` identity for commits; deployment follows the existing Git integration.
