# Wallet funding and savings

The Wallet screen keeps one clothing goal and a remembered public address per network on the current device. A shopper tracks progress against their actual wallet balance. The funds stay spendable in the wallet. Looku does not hold deposits, reserve money or promise a return.

Select **Stellar testnet** for hackathon purchases. Enter a public G-address and choose Get test XLM. Stellar Friendbot funds eligible test accounts with free native XLM, the asset used by the demo checkout. Goals on testnet use XLM. Mainnet goals use USDC. The balance lookup matches both asset code and issuer, so a different asset named USDC does not count. The screen also supports viewing a real Stellar mainnet balance. [Circle asset addresses](https://developers.circle.com/stablecoins/usdc-contract-addresses) · [Stellar Friendbot](https://developers.stellar.org/docs/build/apps/example-application-tutorial/confirmation-modal)

Select **Base mainnet** to fund a wallet through MiniSend. The hosted app exposes a Buy button and asks for a Base recipient address when purchasing USDC with KES. Looku opens that app without passing personal information. The shopper supplies their own address, reviews the amount and fees, and authorizes payment there. Returning to looku and checking the same Base address reads the canonical USDC token contract with an ERC-20 balanceOf query. A wallet balance is evidence of holdings, not proof that a specific MiniSend order settled. [Hosted MiniSend app](https://app.minisend.xyz/) · [Base RPC](https://docs.base.org/base-chain/api-reference/ethereum-json-rpc-api/eth_call)

As verified November 3, 2026, the public MiniSend onramp API delivers USDC on Base to an EVM address. It supports KES via M-Pesa and NGN via bank transfer. Its documented response names Base as the only release chain. A Stellar address or testnet address cannot be substituted. Any separate partner access to Stellar needs its own API contract and confirmation from MiniSend. [Onramp overview](https://docs.minisend.xyz/onramp/overview) · [Create an order](https://docs.minisend.xyz/api-reference/onramp/create-order)

If looku later needs to initiate orders inside the app, MiniSend must enable the merchant account’s onramp scope. Implement authenticated server-side quotes and orders with an idempotency key scoped to each funding attempt. Verify signed webhooks and reconcile with the order endpoint before displaying a transfer receipt. Keep the live API key on the server. The MVP uses the hosted Buy flow without those credentials. [Quote](https://docs.minisend.xyz/api-reference/onramp/quote) · [Webhooks](https://docs.minisend.xyz/onramp/webhooks) · [Order lookup](https://docs.minisend.xyz/api-reference/onramp/get-order)

Wishlist items can each link a separate, initially empty Base receiving account on this device. Fund the address from another wallet or use the hosted MiniSend Buy flow with M-Pesa. Check confirmed funds reads its finalized native USDC balance, including withdrawals. Prices remain in the retailer’s currency. Earlier manual entries remain labeled as notes.
